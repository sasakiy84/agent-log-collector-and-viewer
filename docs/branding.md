# AGrahpite

AGrahpite records and presents everyday agent logs with the ease of jotting a note in a notebook. Its name and graphite motif refer to the familiar mineral used in pencil leads.

The logo is a folded, faceted graphite ribbon. The graphite grays suggest the mineral's layered structure. The production artwork is SVG so it stays sharp in the header, sign-in screen and browser tab.

![AGrahpite logo](../internal/app/static/logo.svg)

Use the spelling `AGrahpite` for the product name. The artwork is in [logo.svg](../internal/app/static/logo.svg); [favicon.svg](../internal/app/static/favicon.svg) adds a white background so the mark remains visible in light and dark browser tabs.

## Existing installations

The executable and release archive prefix remain `agentlog`. Environment variables (`AGENTLOG_TOKEN`, `AGENTLOG_PORT`), Docker Compose service and volume names, database paths, configuration examples, the authentication cookie and header, archive format identifiers, OTLP attributes, and the Go module and repository URLs retain their existing names. Existing collection, authentication and stored data continue to work after a branding update.
